# Rev C routing source

`revC-freerouting.ses` is the accepted Specctra session produced with official
Freerouting 2.2.4 from the `--power-stage-only` board generated by
`scripts/build_board.py`.

The default board build imports that session and then runs
`scripts/repair_freeroute_candidate.py`. The repair script records the reviewed
track, via, ground-stitch, zone-corridor, and two footprint-placement changes
that close the remaining imported-route gaps. KiCad then refills zones and runs
strict DRC with schematic parity; a failing check stops the build.

The post-route repair also keeps the C12/C16 GND stitch outside the 0603 solder
pads. The build explicitly enables missing-courtyard and track-endpoint centering
on vias as errors before DRC.

This routing source makes the CAD result reproducible. It does not replace the
motor, fuse, thermal, transient, enclosure, or first-article validation required
by `docs/validation-plan.md`.
