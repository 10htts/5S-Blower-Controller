# 5S Blower Controller

Open-source reference controller for a two-wire brushed-DC blower powered by a removable 5-series lithium-ion battery (approximately 15–21 V). The design uses a protected low-side N-MOSFET PWM stage, soft start, trigger filtering, voltage/current/temperature protection, an external physical fuse, and a latched fault requiring trigger release.

**Status: CAD CHECKS PASS; NOT YET APPROVED TO ORDER.** KiCad 10 reports zero DRC violations, zero unconnected items, zero schematic-parity issues, and zero ERC errors or warnings. The PCBWay review ZIP is generated, but motor, fuse, mechanical, transient, thermal, and first-article validation remain open. No regulatory certification is claimed.

See [architecture](docs/architecture.md), [wiring](docs/wiring.md), [safety](docs/safety.md), and [revision status](docs/revision-status.md). Firmware tests are host-side and do not replace hardware bring-up.

## Open and edit in KiCad

Open `hardware/blower-controller.kicad_pro` using **File → Open Existing Project** in KiCad. The project contains the editable schematic and PCB.

The canonical KiCad files are generated by `scripts/build_board.py`. A later regeneration will overwrite direct edits to the generated schematic and PCB, so save experimental manual edits under a different project name or port accepted changes into the generator and routing-repair sources.

## Rebuild and export

Run the deterministic board build with KiCad's bundled Python, then generate the current PCBWay review package:

```powershell
& "C:\Program Files\KiCad\10.0\bin\python.exe" scripts\build_board.py
python scripts\export_manufacturing.py --kicad-cli "C:\Program Files\KiCad\10.0\bin\kicad-cli.exe"
```

The current package is `manufacturing/pcbway-review-revC.zip`. It is suitable for PCBWay's Gerber viewer or quotation review, not authorization to place an order.
