# PCBWay release

The current archive is a **preliminary validation package**, not an orderable release. The PCB source still needs an independent electrical review and a clean DRC report.

The final PCBWay upload must contain Gerbers for F.Cu/B.Cu, solder mask, silkscreen, paste if assembly is requested, and Edge.Cuts; Excellon drill files; BOM; CPL/XY placement if assembly is requested; assembly drawings; and fabrication notes. Open the Gerbers in a viewer and verify the board outline, polarity, copper clearance, holes, and silkscreen before uploading.
